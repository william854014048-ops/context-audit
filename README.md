# context-audit

**给你的 Agent 做一次上下文工程体检，让它少读无关资料，清楚地执行任务。**

好的上下文工程，让 Agent 在需要的时候拿到必要的信息：减少不必要的 Token 消耗，同时保留完成任务所需的规则与资料。

context-audit 检查全局提示词、项目提示词及其引用的规则与索引，找出指令含糊、规则冲突、引用失效、读取范围不合理等问题，提供带原文证据的改进建议。

## 支持范围

支持 **Codex、Claude Code、WorkBuddy** 的上下文文件体检：

| Agent | 检查范围 |
|---|---|
| Codex | 用户级与项目级 `AGENTS.md`、覆盖文件及相关配置指定的入口。 |
| Claude Code | 用户级与项目级 `CLAUDE.md`、本地补充文件、原生 `.claude/rules/` 规则目录及明确导入的规则。 |
| WorkBuddy | 用户级 `SOUL.md`、`IDENTITY.md`、`USER.md`、`BOOTSTRAP.md`、`MEMORY.md`，项目根 `AGENTS.md` 与 `.workbuddy/memory/MEMORY.md`。 |

三者都会继续检查入口明确引用的规则与索引；同一项目使用多个 Agent 时，分别判断规则的适用范围。WorkBuddy 的平台自定义指令只有正文可见时才能检查；云记忆缓存、历史日志和运行数据不默认扫描，代码开发兼容配置中未识别的规则会注明未覆盖。

**其他 Agent：** 可以检查已找到或用户指定的指令文件及其引用，识别含糊、冲突、失效引用等问题；尚未内置其专属入口和加载机制，可能漏掉自动加载的文件，无法据此确认整体上下文是否完整、规则实际按什么顺序生效。

## 检查项目与判断方法

先判断每个文件承担什么职责，再追踪它从哪里被引入、在什么条件下读取、需要读多少内容，最后据此检查规则是否清楚、职责与加载范围是否匹配。

| 检查项目 | 判断方法 |
|---|---|
| **文件职责与作用范围** | 区分规则、身份、记忆、状态、索引和参考资料，对照职责依据与实际内容，检查是否混入作用范围不合适的要求；不因一个文件承担多种职责就判错。 |
| **指令清晰度** | 检查是否缺少执行所需的条件、对象、动作、权限或完成标准，导致 AI 必须猜测，且不同猜法会改变结果。 |
| **规则冲突** | 检查同一场景下同时生效的要求，是否无法共同满足，并核对是否已有例外或覆盖规则。 |
| **重复与版本漂移** | 区分共享引用与独立维护的副本，检查重复规则是否出现版本不一致、真源不清或同步风险。 |
| **循环依赖** | 沿强制前置关系查找闭环，检查是否存在互相等待，且缺少起始条件或退出机制。 |
| **引用有效性** | 核对指定文件、章节及工具入口，区分确实缺失、路径不明、访问受限和运行未验证。 |
| **加载关系与范围** | 追踪来源、触发条件和读取范围，区分自动注入、要求读取、条件读取与普通导航；检查任务资料是否被要求常驻、拆分后是否仍被全量引入。 |
| **索引与路由维护** | 检查何时读取哪些资料、读取边界是否明确，以及文件改名、迁移后，相关索引和引用如何更新。 |

每项先判断是否适用，再判断是否存在问题。没有索引，不会因此被判为缺陷。

检查从当前工作目录出发，先核对已知配置，再定位指令入口、原生规则目录及其明确引用；不会扫描整个项目或知识库。

## 体检报告

先给问题与改进建议。每条发现都包含：

| 位置与原文证据 | 问题 | 原因与影响 | 具体改进建议 |
|---|---|---|---|

例如，指令写着“重要修改先确认”，却没有定义“重要”。报告会指出缺少审批触发条件，并提出需要澄清的内容，不擅自替用户设定门槛。

报告区分**明确问题、可能风险和可选建议**，随后用一份简表说明文件职责、加载关系和检查覆盖情况，补充未能确认的部分。Skill 只做检查，由你审核并决定是否修改。

## 安装

以本 GitHub 仓库 `main` 分支为最新发布版本，各客户端从这里安装和更新。

将下面这段话发送给支持 Skill 安装的 Agent：

> 请阅读 https://github.com/william854014048-ops/context-audit 的 README，从 main 分支安装或更新 context-audit。Skill 位于仓库根目录，请从同一次提交完整获取 SKILL.md、references/ 和 agents/，核对配套文件是否齐全，不要只复制 SKILL.md；如已有用户自定义改动，先说明差异。

如果安装器采用 Git 稀疏检出，选择仓库根目录可能遗漏子目录。请使用完整下载或完整克隆，并核对文件。
